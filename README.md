## FAQ

### What is XCutors?

XCutors is a unified collection of popular Roblox executor tools for Windows, providing a convenient way to access Volt, Synapse Z, Potassium, Wave, and a universal loader from a single package.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11. Administrator privileges are required for installation and execution.

### Is XCutors free to use?

Yes, XCutors is free to download and use. Some individual executors within the collection may offer premium features separately.

### How do I update XCutors?

The loader includes a built-in update checker that notifies you when new versions are available. You can also manually check the GitHub Releases page for updates.

### Where can I find scripts to use?

The package includes a built-in script hub with categorized scripts. You can also find scripts from trusted community sources and paste them directly into the executor.

### Can I use multiple executors at once?

You can switch between executors in the interface, but only one executor should be active at a time to avoid conflicts.

### What should I do if an executor fails to load?

Ensure you're running the application as administrator, your anticomponent is not blocking the files, and your Windows version meets the requirements. Check the FAQ troubleshooting section for specific error codes.

### How do I add custom scripts?

Use the built-in script editor to write or paste code, then click Save to add it to your library. You can also import .lua files directly from your file system.
